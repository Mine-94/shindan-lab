# しんだんラボ — 話題の性格診断・タイプ分けサイト（日本版）

韓国版「요즘테스트」の翻訳ではなく、日本市場のデータ調査に基づいて**独自に企画した**診断3種を収録した日本語サイトです。Node.js/Express製、結果共有リンクごとにサーバー側でOpen Graph / Twitter Cardタグを動的に出し分けることで、「私の結果は"OOO"だった」という形でX（旧Twitter）やLINE、Instagramなどに共有された際にリンクプレビューが正しく表示されるよう設計しています。

## なぜこの3診断なのか（データに基づく判断根拠）

プロジェクト内ドキュメント「일본시장-진출-리서치-및-결정.md」の調査結果に基づきます。要点:

- 日本にはshindanmaker.com等、無料テキスト診断のUGCプラットフォームが既に定着済み（累計100万件超の診断投稿）。**韓国の밈を直訳しても、この既存プラットフォームと同じ土俵で勝てる根拠は薄い**ため、日本固有の切り口で差別化しました。
- **推し活タイプ診断**：韓国にはない「推し活」文化を題材にした、日本固有企画。
- **本当の性格タイプ診断**：日本でも2025年時点でMBTIブームが続いている根拠（16Personalitiesベースの2025年集計記事）を確認済み。ただし公式MBTIの商標・コードは使わず独自タイプ名で構成（韓国版の`vibe-shift`診断と同じ戦略）。
- **人生の選択バランスゲーム**：フォーマットの言語・文化依存度が低く、移植コストが低いため踏襲。
- 収益性（AdSense RPM等）に関する公開データは出典間で大きく矛盾しており、**事前の収益予測はあえて行っていません**。運営開始後にAdSenseコンソールで実測することを前提にした「損失の少ないポートフォリオ実験」として位置づけています。

## 1. ローカルで実行する

```bash
npm install
npm start
```

`http://localhost:3000` にアクセス。APIキー不要で、インストール後すぐ動作します。

## 2. 新しい診断を追加する方法

`data/quizzes.js` の配列にオブジェクトを1つ追加するだけで、ホーム画面・ルーティングに自動反映されます。韓国版と同じ「トレンドが出るたびに素早く追加する」ポートフォリオ戦略を想定した構造です。

## 3. Renderへのデプロイ

既存サイトと同じ手順です。

1. このプロジェクトフォルダをGitHubリポジトリにアップロード。
2. Renderダッシュボードで **New > Web Service** からリポジトリを接続。
3. Build Command: `npm install`、Start Command: `npm start`。
4. デプロイ後に発行された実際のドメインを `views/render.js` の `SITE_URL` 環境変数として設定してください。**結果共有リンクのog:url / twitter:cardが正しいドメインを指すために重要です**。Render環境変数に `SITE_URL=https://実際のドメイン` の形式で追加してください。

## 4. 広告（AdSense等）連携

各ページの `<div class="ad-placeholder">` に広告コードを差し込むだけで導入できます。診断の回答中の画面には広告を配置していません（誤タップ防止・完了率重視の意図的な設計、韓国版と同じ方針）。

**注意（リサーチ由来）**: 日本向けAdSense RPMについては信頼できる公開データが見つからず、出典間で数値が大きく食い違っていました。予算計画には使わず、実運用後にAdSenseコンソールで直接数値を確認してください。A8.net等の日本ローカル広告網は、診断・エンタメ系サイトでの活用実績が未確認のため、まずはAdSenseのみでの運用を推奨します。

## 5. トラフィック戦略メモ

- 日本ではSNSの使い分けが韓国と異なります（SHIBUYA109 Lab 2025年Z世代調査：X＝「自分の考え・近況」共有で52.8%が1位利用、Instagram＝キュレーションされたビジュアル用途41.6%）。したがって**X（Twitter Card）最適化を最優先**し、Instagramでは結果画面のスクリーンショットをストーリーズでシェアする使われ方を想定しています（画像生成OGPは今後の拡張候補）。
- 診断ジャンル自体は2023〜2024年の複数事例（fasme・Morinaga・LIONなどの診断キャンペーン、参加9万〜130万件）で有効性が確認されていますが、直近1年（2025-2026）の新規バイラル事例は確認できていません。**ジャンルの有効性は中程度の確信度**として扱ってください。
- shindanmaker.comという強力な既存プレイヤーがいるため、「同じことを翻訳する」のではなく「日本固有の題材・高い完成度のデザイン」で差別化する方針を維持してください。
