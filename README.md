# しんだんラボ — 姓名判断・血液型占い・四柱推命 × 性格診断サイト（日本版）

日本語圏向けの総合診断サイトです。姓名判断・血液型占い・簡易四柱推命の3ツール、複数の独自性格診断、16タイプ簡易診断と関係別相性チェックを提供します。日本版は短期収益を保証するものではなく、Search Console・GA4・AdSenseの実測値で継続可否を判断する検証トラックです。

## 0. 読む前に — この拡張の前提（データに基づく判断根拠）

プロジェクト内ドキュメント `일본-점술운세진단-SEO-리서치.md` の調査結果に基づきます。**楽観的な話だけでなく、うまくいかない可能性も含めて正直に書きます。**

- **可能性**: 姓名判断・四柱推命は「命名」や自己理解という継続需要があり、性格診断には共有導線があります。ただし公開されている検索量・広告単価の推計は出典差が大きいため、収益計画には使わず実測します。
- **悪いニュース（正直に）**: 姓名判断・四柱推命の検索上位は、LINE占い・エキサイト占い・cocoloniなど**20年選手の上場/大手系列企業＋セレブ占い師IPが独占**しており、新規ドメインがこれらの頭語（ヘッドターム）で勝てる証拠は見つかりませんでした。確認できた唯一の小規模成功例でも**PVが伸びるまで1.5〜2年**かかっており、しかもそれは2023年のHelpful Content Update / AI Overviews以前のデータです。つまり「占いで日本のGoogle検索を今すぐ制覇する」は非現実的な期待です。
- **方針**: ヘッドタームでの短期決戦は狙わず、(1) 姓名判断の固有URLを活かしたロングテールSEO、(2) 性格診断の共有流入、(3) AdSenseを検証します。アフィリエイトは承認済みで日本向け利用条件を満たす案件がある場合だけ補助的に使います。

## 1. サイト構成

### 占い（新規追加、計算ロジックあり）
- **姓名判断** (`/meimei`) — 姓・名の漢字画数から天格・人格・地格・外格・総格の五格を算出し吉凶判定。名前ごとに固有URL（`/meimei/r/姓/名`）が生成されるため、検索されるたびにロングテールで拾える設計。
- **血液型占い** (`/ketsueki`) — A/B/O/AB型の性格タイプ＋相手の血液型を選ぶと相性目安も表示。
- **十干タイプ診断／簡易四柱推命** (`/shichuu`) — 生年月日から十干（甲〜癸）を算出し、五行タイプを診断。

### タイプ診断（選択式クイズ）
- 推し活タイプ診断 / 本当の性格タイプ診断 / 人生の選択バランスゲーム / かくれキャラ診断（`/q/:id`）

### 16タイプ・MBTI関連（非公式）
- **16タイプ簡易診断** (`/16type/test`) — 20問でE/I・S/N・T/F・J/Pの回答傾向を整理。
- **16タイプ相性チェック** (`/16type/compatibility`) — 恋愛・友達・仕事・家族の4場面で、二人の違いと会話のコツを表示。
- **16タイプ性格一覧** (`/16type`) — 16タイプそれぞれの強み・注意点・恋愛・友情・仕事・コミュニケーションを独自解説。

これらは公式MBTI®ではありません。MBTI®はThe Myers-Briggs Companyの登録商標であり、当サイトは日本MBTI協会およびThe Myers-Briggs Companyと関係のない非公式エンタメコンテンツです。

## 2. 占いツールの計算方法と限界（正直な注記）

実装前に手法を調査した上で作っています。誇張せず、簡易版であることを明記しています。

- **姓名判断**: 熊崎式の五格計算式を実装。画数は現代（新字体）基準（`lib/kanji-strokes.json`、13,108字収録、npm `kanji-data` パッケージのKANJIDICデータより抽出）。**正統な流派では旧字体（康熙字典体）の画数を使う場合があり、結果が変わることがあります** — これは調査で確認した既知の簡略化ポイントで、カジュアル系サイトの多くも同様に新字体で計算しています。81数の吉凶表は確認できた34の吉数のみを採用し、それ以外を凶とする2値判定の簡易版です。ひらがな・カタカナの名前には対応していません（エラー画面を表示）。
- **簡易四柱推命**: 本格的な四柱推命は月柱の計算に節入り（正確な太陽黄経の時刻）が必要で、固定日では安全に近似できないため実装していません。年柱（十干）のみを `(year-4) mod 10` で算出する簡易版です（1984年=甲子、1966年=丙午という有名な史実で検証済み）。立春（2/4）を年の境目として扱う簡易ルールを実装していますが、実際の節入り時刻とは年によって±1日ずれる場合があります。
- **血液型占い**: 相性表は編集部独自の目安です（正式な標準アルゴリズムは存在しないというのが調査結果— 実在する占いサイトも同様に手作業でマトリクスを作っています）。血液型と性格の関連は科学的に証明されていない旨、フッター・各結果ページに明記しています。

## 3. アフィリエイト導線について

承認済みの広告URLがある場合だけ、結果ページ下部に「PR」カードを表示します。`AFFILIATE_URL` が未設定ならカード自体を出しません。URLは必ず広告ネットワークが発行したものを使い、案件の媒体条件・対象地域・表現ルールを確認してください。リンクには `rel="sponsored nofollow"` が自動付与され、クリックは GA4 の `affiliate_outbound_click` として計測されます。

- `AFFILIATE_URL`: 承認済み広告URL（必須。未設定時は非表示）
- `AFFILIATE_TITLE`: PRカードの見出し（任意）
- `AFFILIATE_DESCRIPTION`: PRカードの説明（任意。広告主の表現ルールに合わせる）

## 5. 新しい診断/占いを追加する方法

- タイプ診断を追加: `data/quizzes.js` の配列にオブジェクトを1つ追加。
- 占いツールをホーム画面のカードに追加: `data/fortune-tools.js` に追記。
- 十干タイプの文言を調整: `data/fortune-content.js` の `STEM_CONTENT` を編集。

## 6. Renderへのデプロイ

1. このプロジェクトフォルダをGitHubリポジトリにアップロード。
2. Renderダッシュボードで **New > Web Service** からリポジトリを接続。
3. Build Command: `npm install`、Start Command: `npm start`。
4. デプロイ後に発行された実際のドメインを `SITE_URL` 環境変数として設定してください。Render環境変数に `SITE_URL=https://実際のドメイン` の形式で追加してください。**og:url / twitter:card / サイトマップ / robots.txt すべてこの値を使うため必須です。**
5. （任意・推奨）Google Search Consoleでサイトを登録後、「その他の方法 > HTMLタグ」で発行される`content`の値を `GOOGLE_SITE_VERIFICATION` 環境変数に設定すると、所有権確認タグが自動で出力されます。
6. `ADSENSE_CLIENT_ID=ca-pub-...` を設定するとAdSenseスクリプトが出力され、`/ads.txt` も同じパブリッシャーIDで応答します。
7. `GA_MEASUREMENT_ID=G-...` を設定すると、ページビューに加えて `tool_submit`・`quiz_start`・`quiz_complete`・`share_success`・`outbound_click` を計測します。

## 7. SEO関連

- `/sitemap.xml`・`/robots.txt` はサーバーが `SITE_URL` を使って自動生成します（静的ファイルではないので手動編集不要）。
- **2026年8月のSEO修正**: `/ketsueki/r/:type`（4件）・重複を除いた血液型ペア（10件）・`/shichuu/r/:stemKey`（10件）をsitemapへ追加しました。`data/seo-longtail.js` の姓名判断52件を合わせ、sitemapは静的9件+十干10件+血液型単4件+血液型ペア10件+姓名判断52件=85件です。
- 各フォーム画面（`/shichuu` `/ketsueki` `/meimei`）に、上記の動的結果ページへの内部リンクグリッドを追加しました（クローラビリティ向上 + ユーザーの再訪導線）。
- 各ページに `canonical` タグを設定済みです。
- 姓名判断・血液型占い・十干タイプの各結果ページは、選択式クイズより長めの説明文を入れてSEO上のコンテンツの厚みを持たせています。
- Google Search Console所有権確認用の `<meta name="google-site-verification">` タグを、環境変数 `GOOGLE_SITE_VERIFICATION` を設定すると自動出力するようにしました（未設定時は何も出ません）。Search Consoleの「その他の方法 > HTMLタグ」で取得した`content`の値だけをRenderの環境変数に設定してください。

## 8. 広告（AdSense等）連携

`ADSENSE_CLIENT_ID` を設定すると全ページの`<head>`にAdSenseスクリプトが出力されます。`/ads.txt` は同じIDから販売者レコードを自動生成します。診断の回答中の画面には広告を配置していません。

**注意（リサーチ由来）**: 日本向けAdSense RPMについては信頼できる公開データが見つからず、出典間で数値が大きく食い違っていました。予算計画には使わず、実運用後にAdSenseコンソールで直接数値を確認してください。占いジャンルはAdSenseの制限カテゴリには該当しません（公式ポリシーで確認済み）。**アフィリエイト（第3節参照）の方が収益インパクトは大きい可能性が高いです。**

## 16タイプ関係別SEO・招待比較ループ

日本語検索の関係別意図と、SNS共有後の再訪・比較行動を一つにつなぐため、次の導線を実装しています。

- `/16type/love`・`/friend`・`/work`・`/family`: 関係別の独自解説、FAQ、二人のタイプ選択フォーム
- 16タイプ結果ページ: 友達・恋人へ専用比較リンクを送る招待ボタン
- 招待リンク経由の診断: 回答後、そのまま二人の相性結果へ進めるCTA
- 共有リンク・共有画像: UTMを付与し、GA4で流入元を区別
- GA4: `relation_guide_view`、`relation_guide_submit`、`type16_invite_share`、`share_landing`、`type16_comparison_click`

256組の薄い相性ページは生成せず、検索意図が明確で十分な独自説明を持つ4つの関係ガイドだけをインデックス対象にしています。
