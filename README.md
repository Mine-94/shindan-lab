# しんだんラボ — 姓名判断・血液型占い・四柱推命 × 性格診断サイト（日本版）

日本語圏向けの総合診断サイトです。もともとはSNSシェア狙いの性格診断3種のみでしたが、**「日本のGoogle検索市場を取りにいく」という方針転換**に伴い、実際に検索需要が確認できた姓名判断・血液型占い・簡易四柱推命の3ツールを追加し、「占い」と「タイプ診断」の2セクション構成に拡張しました。

## 0. 読む前に — この拡張の前提（データに基づく判断根拠）

プロジェクト内ドキュメント `일본-점술운세진단-SEO-리서치.md` の調査結果に基づきます。**楽観的な話だけでなく、うまくいかない可能性も含めて正直に書きます。**

- **良いニュース**: MBTI関連の検索需要は強い（民間データで「MBTI診断」単体が月間約277万件、クラスター全体で月間約2,500万件という推計あり、単一ソースのため中程度の確信度）。姓名判断・四柱推命は「命名」という実需に紐づく安定需要。アフィリエイト（電話占いヴェルニ等への送客で1件¥8,000〜15,000）は表示広告よりずっと大きい収益レバーであることも確認済み。AdSenseの占いコンテンツに対する制限もなし。
- **悪いニュース（正直に）**: 姓名判断・四柱推命の検索上位は、LINE占い・エキサイト占い・cocoloniなど**20年選手の上場/大手系列企業＋セレブ占い師IPが独占**しており、新規ドメインがこれらの頭語（ヘッドターム）で勝てる証拠は見つかりませんでした。確認できた唯一の小規模成功例でも**PVが伸びるまで1.5〜2年**かかっており、しかもそれは2023年のHelpful Content Update / AI Overviews以前のデータです。つまり「占いで日本のGoogle検索を今すぐ制覇する」は非現実的な期待です。
- **方針**: ヘッドタームでの短期決戦は狙わず、(1) 姓名判断は「入力した名前ごとに固有URLが生まれる」構造を活かしたロングテールSEO、(2) MBTI隣接コンテンツ（本当の性格タイプ診断など）を軸に、(3) 表示広告に加えて占い相談サービスへのアフィリエイト送客を収益の柱に据える、という中長期の複合戦略で進めます。詳細は上記リサーチ文書を参照してください。

## 1. サイト構成

### 占い（新規追加、計算ロジックあり）
- **姓名判断** (`/meimei`) — 姓・名の漢字画数から天格・人格・地格・外格・総格の五格を算出し吉凶判定。名前ごとに固有URL（`/meimei/r/姓/名`）が生成されるため、検索されるたびにロングテールで拾える設計。
- **血液型占い** (`/ketsueki`) — A/B/O/AB型の性格タイプ＋相手の血液型を選ぶと相性目安も表示。
- **十干タイプ診断／簡易四柱推命** (`/shichuu`) — 生年月日から十干（甲〜癸）を算出し、五行タイプを診断。

### タイプ診断（既存、選択式クイズ）
- 推し活タイプ診断 / 本当の性格タイプ診断 / 人生の選択バランスゲーム（`/q/:id`）

## 2. 占いツールの計算方法と限界（正直な注記）

実装前に手法を調査した上で作っています。誇張せず、簡易版であることを明記しています。

- **姓名判断**: 熊崎式の五格計算式を実装。画数は現代（新字体）基準（`lib/kanji-strokes.json`、13,108字収録、npm `kanji-data` パッケージのKANJIDICデータより抽出）。**正統な流派では旧字体（康熙字典体）の画数を使う場合があり、結果が変わることがあります** — これは調査で確認した既知の簡略化ポイントで、カジュアル系サイトの多くも同様に新字体で計算しています。81数の吉凶表は確認できた34の吉数のみを採用し、それ以外を凶とする2値判定の簡易版です。ひらがな・カタカナの名前には対応していません（エラー画面を表示）。
- **簡易四柱推命**: 本格的な四柱推命は月柱の計算に節入り（正確な太陽黄経の時刻）が必要で、固定日では安全に近似できないため実装していません。年柱（十干）のみを `(year-4) mod 10` で算出する簡易版です（1984年=甲子、1966年=丙午という有名な史実で検証済み）。立春（2/4）を年の境目として扱う簡易ルールを実装していますが、実際の節入り時刻とは年によって±1日ずれる場合があります。
- **血液型占い**: 相性表は編集部独自の目安です（正式な標準アルゴリズムは存在しないというのが調査結果— 実在する占いサイトも同様に手作業でマトリクスを作っています）。血液型と性格の関連は科学的に証明されていない旨、フッター・各結果ページに明記しています。

## 3. アフィリエイト導線について

`views/render.js` の `affiliateSlot()` が、姓名判断・血液型占い・四柱推命の結果ページ下部に「PR」表示付きのカードを出します。**現状はリンク先が `#`（未設定）のプレースホルダーです。** 電話占いヴェルニ・カリスなどのアフィリエイトプログラムに登録後、`affiliateSlot()` 内の `href="#"` を実際のアフィリエイトリンクに置き換えてください。ステルスマーケティング規制（2023年10月施行）により、広告であることが分かる表示（現状の「PR」ラベル）を維持することが必須です。

## 4. ローカルで実行する

```bash
npm install
npm start
```

`http://localhost:3000` にアクセス。APIキー不要で、インストール後すぐ動作します。

## 5. 新しい診断/占いを追加する方法

- タイプ診断を追加: `data/quizzes.js` の配列にオブジェクトを1つ追加。
- 占いツールをホーム画面のカードに追加: `data/fortune-tools.js` に追記。
- 十干タイプの文言を調整: `data/fortune-content.js` の `STEM_CONTENT` を編集。

## 6. Renderへのデプロイ

1. このプロジェクトフォルダをGitHubリポジトリにアップロード。
2. Renderダッシュボードで **New > Web Service** からリポジトリを接続。
3. Build Command: `npm install`、Start Command: `npm start`。
4. デプロイ後に発行された実際のドメインを `SITE_URL` 環境変数として設定してください。Render環境変数に `SITE_URL=https://実際のドメイン` の形式で追加してください。**og:url / twitter:card / サイトマップ / robots.txt すべてこの値を使うため必須です。**

## 7. SEO関連

- `/sitemap.xml`・`/robots.txt` はサーバーが `SITE_URL` を使って自動生成します（静的ファイルではないので手動編集不要）。姓名判断の結果ページのような無限に生成されるロングテールページはサイトマップに含まれませんが、内部リンクを辿ってGoogleにクロールされる想定です。
- 各ページに `canonical` タグを設定済みです。
- 姓名判断・血液型占い・十干タイプの各結果ページは、選択式クイズより長めの説明文を入れてSEO上のコンテンツの厚みを持たせています。

## 8. 広告（AdSense等）連携

各ページの `<div class="ad-placeholder">` に広告コードを差し込むだけで導入できます。診断の回答中の画面には広告を配置していません。

**注意（リサーチ由来）**: 日本向けAdSense RPMについては信頼できる公開データが見つからず、出典間で数値が大きく食い違っていました。予算計画には使わず、実運用後にAdSenseコンソールで直接数値を確認してください。占いジャンルはAdSenseの制限カテゴリには該当しません（公式ポリシーで確認済み）。**アフィリエイト（第3節参照）の方が収益インパクトは大きい可能性が高いです。**

## 9. トラフィック戦略メモ

- X（Twitter Card）最適化を優先し、Instagramでは結果画面のスクリーンショット共有を想定（画像生成OGPは今後の拡張候補）。
