# しんだんラボ ホーム表示優先度モデル

最終更新: 2026-09-02（JST）

## 目的

ホームの上部を運営者の感覚だけで並べず、日本の公開調査、実サービスの利用行動、検索意図、初回訪問者の使いやすさを数値化して並べるための編集モデルです。

現時点の当サイト固有データは、直近確認時点でGoogle Search Consoleのインデックス1件、7日間の表示3回、クリック0回と小さく、ページ別の勝者を判断できる量ではありません。そのため、まず外部データを使った暫定順位を採用し、GA4のホーム表示・クリック・診断開始・完了・共有データが十分にたまった後にサイト固有順位へ切り替えます。

## 配点

- 日本市場の需要: 40%
- 繰り返し利用・共有可能性: 25%
- SEO上の入口を増やせる可能性: 20%
- 初回訪問者が迷わず始められるか: 15%

各項目を0〜100点で評価し、加重平均を小数第1位まで表示します。この点数は公的な市場シェアでも検索ボリュームでもなく、ホーム配置のための編集スコアです。

## 主な外部数値

- 2024年11月の大学生500名調査では、ネット上でMBTI診断と呼ばれる16タイプ診断を使ったことがある人が96.4%。対象が上位大学の学生に偏るため、日本全体の割合としては扱いません。
- 2025年1月のアプリ利用者21,985名調査では、16タイプ診断を1回以上受けた人が合計13%。母集団が異なるため、上記96.4%と平均せず、若年層集中と一般層との差を示す材料として使います。
- 16タイプ相性サービスの2026年1月24日〜8月19日ログでは、診断行動14,507件、ユニーク利用者6,245人、ユニーク診断8,743件。
- 同サービスの年代回答者2,514人では、17歳以下の43.0%が友達との相性を確認。関係選択肢拡張後、友達診断が41件から1,566件へ約38倍。
- 推し活調査では、日本の推し活人口推計約1,940万人、実施率24.0%。別調査では「推しがいる・ある」が40.9%、20代57.4%。
- 2026年の占い調査1,020名では、よく見る占いが星座71.9%、血液型24.3%、タロット19.6%、四柱推命15.5%。占いを見る媒体はWebサイト62.2%。

## 実装する並び

1. ファーストビュー: 16タイプ簡易診断、16タイプ相性、推し活タイプ診断
2. 次のセクション: タイプ診断
3. その次: 占い
4. タイプ診断内: 推し活 → 本当の性格 → かくれキャラ → 人生バランス
5. 占い内: 血液型 → 十干 → 姓名判断

16タイプ性格一覧はファーストビュー見出しのリンクから直接移動できるようにし、同じカードを重複表示しません。

## サイト固有データへの切替条件

ホーム上部のカードには以下のGA4イベントを追加します。

- `home_priority_view`: 優先枠が表示された回数
- `home_priority_click`: 各カードが押された回数、順位、編集スコア
- 既存の `quiz_start` / `quiz_complete` / `type16_start` / `type16_complete` / `share_success` と組み合わせて評価

最低300回の優先枠表示と、各候補30回以上の開始がそろうまでは外部モデルを維持します。条件達成後は、ホームCTR 40%、完了率30%、共有率20%、再訪寄与10%のサイト固有スコアで再計算します。少数データによる毎日の順位入れ替えは行いません。
