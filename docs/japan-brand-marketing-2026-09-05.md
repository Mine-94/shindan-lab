## 5. UTM 규칙

형식:

`utm_source={channel}&utm_medium={format}&utm_campaign={topic_yyyymm}`

예시:

- X 일반 게시물: `utm_source=x&utm_medium=social&utm_campaign=type16_celebrity_202609`
- Instagram 프로필: `utm_source=instagram&utm_medium=profile&utm_campaign=type16_202609`
- Instagram Story: `utm_source=instagram&utm_medium=story&utm_campaign=love_compatibility_202609`
- Threads: `utm_source=threads&utm_medium=social&utm_campaign=friend_compatibility_202609`

## 6. 판단 지표

첫 14일에는 절대 방문자 수보다 퍼널의 끊기는 지점을 본다.

| 단계 | 확인 지표 | 내부 1차 판단선 |
|---|---|---:|
| 외부 게시물 → 사이트 | 링크 CTR | 1.5% 이상이면 소재 유지 후보 |
| 랜딩 → 진단 시작 | 시작률 | 15% 이상 |
| 진단 시작 → 완료 | 완료율 | 55% 이상 |
| 결과 → 유명인 섹션 노출 | 섹션 도달률 | 40% 이상 |
| 유명인 섹션 → 유형/근거 클릭 | 클릭률 | 5% 이상 |
| 결과 → 링크·이미지 공유 | 공유율 | 3% 이상 |
| 결과 → 친구·연인 초대 | 초대율 | 5% 이상 |
| 초대 방문 → 진단 완료 | 완료율 | 35% 이상 |

이 수치는 업계 평균이 아니라 초기 실험용 내부 판단선이다. 노출 100회 미만, 진단 시작 30회 미만의 소재는 승패를 확정하지 않는다.

### 개선 우선순위

- 노출이 낮다: 제목·첫 이미지·배포 채널을 수정한다.
- 클릭은 높고 시작률이 낮다: 랜딩 첫 문장과 버튼을 수정한다.
- 시작률은 높고 완료율이 낮다: 문항 표현, 모바일 버튼, 진행률을 점검한다.
- 완료율은 높고 공유율이 낮다: 결과 카드와 공유 문구를 수정한다.
- 공유 방문은 있지만 초대 완료가 낮다: 초대받은 화면의 설명과 첫 버튼을 수정한다.

## 7. 브랜드 보호 규칙

- 공식 MBTI® 검사 또는 협회 제휴처럼 표현하지 않는다.
- 유명인 유형은 본인·공식 공개 근거가 확인된 경우만 수록하고 확인 링크와 날짜를 유지한다.
- 유명인 사진은 사용 권한이 확인되기 전에는 게시물·사이트에 넣지 않는다.
- 개인의 정신건강, 성적 지향, 질병, 정치 성향, 범죄 가능성을 유형으로 추측하지 않는다.
- 결과를 채용, 교육, 교제, 배제의 근거로 쓰도록 유도하지 않는다.
- 링크 단축기로 목적지를 숨기지 않는다.
- 댓글·DM 자동화, 팔로우 구매, 클릭 교환, 유료 저품질 백링크를 사용하지 않는다.
- 커뮤니티에 참여할 때 질문에 대한 답변이 홍보 링크보다 앞서야 한다.
