# しんだんラボ 일본 검색·트렌드 일일 모니터링 로그

이 문서는 일본판 `しんだんラボ`만을 대상으로 한다. 새로운 기록이 위에 오도록 날짜 역순으로 누적하며, 단순히 유행어를 모으는 데서 끝내지 않고 **기존 진단 개선 / 신규 진단 추가 / 보류** 중 하나의 결론과 실제 실행 내역을 함께 남긴다.

## 운영 범위와 우선순위

### 핵심 모니터링

1. **Google Japan / Google Trends**: 검색 의도, 현재 SERP 경쟁도, 급상승 검색 신호
2. **Yahoo! JAPAN 검색·リアルタイム検索**: X에서 실제 공유되는 결과 문구·해시태그·확산 포맷
3. **Bing / Microsoft Copilot**: Bing 색인 여부, 경쟁 결과, IndexNow 반영 상태
4. **YouTube / Instagram / Threads / X**: 일본 사용자가 진단 결과를 어떤 이미지·문장·캐릭터 형식으로 공유하는지 확인
5. **Reddit**: 일본 관련 커뮤니티에서 발생하는 보조 신호만 참고

### 보조 모니터링

- **Naver**: 일본어 사이트의 핵심 유입원으로 동일 비중을 두지 않는다. 한국 이용자가 일본 트렌드를 찾는 교차 검색이나 일본어 키워드의 한국 내 확산 여부만 보조 확인한다.
- **Firefox**: 검색엔진이 아니라 브라우저이므로 별도 키워드 데이터원으로 집계하지 않는다. Firefox 이용자가 선택한 Google·Bing·DuckDuckGo 등의 결과를 해당 검색엔진 기준으로 본다.

## 확장 판단 원칙

1. 검색·SNS 트렌드를 먼저 확인한다.
2. 같은 검색 의도를 이미 다루는 진단이 있으면 신규 추가보다 기존 콘텐츠를 먼저 보강한다.
3. 신규 진단은 일본어 검색 수요, 공유 가능성, 기존 페이지와의 비중복성, 독자적인 질문·결과를 충분히 만들 수 있는지 확인한 뒤 추가한다.
4. 유행한 서비스의 캐릭터명·문장·진단축을 복제하지 않는다.
5. 상표·저작권·개인정보 위험이 큰 주제는 검색량이 있어도 보류한다.
6. 결과 유형 수를 16개·64개로 늘리는 것 자체를 가치로 보지 않는다. 각 결과에 읽을 만한 고유 해설이 없으면 추가하지 않는다.
7. Search Console·GA4·AdSense 실측값이 생기면 외부 추정치보다 우선한다.

## 2026-09-02 — 16타입·MBTI 관련 검색 의도 확장

### 오늘 확인한 일본 시장 신호

- 2026년 1~8월 일본의 16타입 상성 서비스 한 곳이 공개한 이용 로그에서는 14,507건의 진단 행동과 6,245명의 고유 이용자가 집계됐다. 해당 서비스 내부 데이터라 일본 전체를 대표하지는 않지만, `16タイプ 相性`이 실제 반복 이용되는 도구형 검색 의도라는 근거로 참고할 수 있다.
- 같은 서비스의 2026년 8월 27일 공개 자료에서는 17세 이하 이용자의 43.0%가 친구 관계로 상성을 확인했고, 관계 선택지를 늘린 뒤 친구 진단 건수가 크게 늘었다. 따라서 연애만 제공하기보다 친구·직장·가족까지 관계 맥락을 나누는 편이 이용 목적과 맞는다.
- 일본에서는 2026년에도 16타입 형식을 직업·돈·간호사·취미 등 특정 상황에 적용한 신규 진단이 계속 공개되고 있다. 단순히 16개 이름을 나열하는 페이지보다, 진단 후 실제 행동 팁까지 연결하는 구조가 공통적이다.
- 일본MBTI협회는 무료 16타입 성격진단과 정식 MBTI®가 전혀 다른 것이라고 명확히 안내한다. 검색어 유입을 위해 `MBTI`를 쓰더라도 공식 검사처럼 표시하거나 제휴 관계를 암시하면 안 된다.

### 오늘의 판단

사용자의 추가 지시인 “MBTI 관련 궁합, 유형, 심리테스트도 추가”를 반영해, 얇은 퀴즈 여러 개 대신 하나의 16타입 허브를 구축한다.

1. `16タイプ簡易診断`: 20문항, E/I·S/N·T/F·J/P 각 5문항
2. `16タイプ相性チェック`: 연애·친구·직장·가족 4개 관계
3. `16タイプ性格一覧`: 16개 유형별 강점·주의점·연애·친구·직장·대화 팁

### 구현 원칙

- 16개 유형명과 설명, 20개 질문, 상성 계산 문구를 모두 자체 제작했다.
- 16Personalities의 캐릭터명·그림·설명문을 복제하지 않았다.
- 모든 관련 페이지에 `公式MBTI®ではありません` 고지와 일본MBTI협회 안내 링크를 표시한다.
- 상성 수치는 과학적 예측값이 아니라 4개 축과 관계 맥락을 조합한 편집부 독자 기준임을 밝힌다.
- 256개 조합별 얇은 SEO 페이지를 만들지 않는다. 상성 쿼리 결과는 `noindex, follow`로 처리하고, 도구 본문 한 페이지에 설명과 FAQ를 집중한다.
- 반대로 16개 유형 상세 페이지는 각각 고유한 장문 해설을 제공하므로 사이트맵에 포함한다.
- 추가 후 사이트맵은 88개에서 107개 URL로 증가한다.

## 2026-09-01

### 오늘 확인한 일본 시장 신호

#### 1. 연애 특화 진단의 세분화가 가장 강한 흐름

- `恋愛タイプ診断`, `ラブタイプ診断`, `Love Type 16`, `Love Character 64`가 일본 매체와 Yahoo! リアルタイム検索에서 반복적으로 확인됐다.
- 2025년 말 16유형에서 64유형으로 확장된 포맷이 2026년에도 기사·SNS 결과 공유로 이어지고 있다.
- 핵심은 단순히 유형 수가 많은 것이 아니라, **연애라는 단일 상황에 특화된 축, 캐릭터명, 타입 코드, 상대 유형과의 상성, 결과 카드 공유**가 결합된 점이다.

판단: **신규 후보 1순위는 연애 스타일 진단**이다. 다만 기존 인기 서비스의 4자 코드·캐릭터·6개 축을 복제하지 않고, しんだんラボ만의 질문과 해설 구조를 먼저 설계해야 한다. 오늘 바로 얇은 신규 페이지를 만들지는 않는다.

#### 2. 推し活 진단은 계속 유효하지만 현재 사이트 버전은 얕다

- 2026년 6월 공개된 일본 공식 앱형 콘텐츠는 14문항·16유형·오리지널 캐릭터·SNS 공유 구조를 사용했다.
- 2026년 8월에도 별도의 `推しタイプ診断`이 새로 공개됐고, Yahoo! リアルタイム検索에는 `推し活64タイプ診断` 결과와 희귀도 문구가 공유되고 있다.
- 현재 しんだんラボ에는 이미 `あなたの推し活タイプ診断`이 있으므로 같은 주제의 신규 진단을 하나 더 만드는 것은 중복이다.

판단: **신규 추가가 아니라 기존 推し活 진단 개선**이 우선이다. 오늘은 4개 결과 모두에 강점·주의점·관계 팁·실행 팁을 추가하고, 시작 페이지에 판정 기준을 설명한다. 향후 GA4 완료율과 공유율을 확인한 뒤 8~16유형 확장을 검토한다.

#### 3. 姓名判断·四柱推命·血液型占い은 상시 수요지만 헤드 키워드는 강한 레드오션

- `姓名判断 相性`, `四柱推命 無料`, `血液型占い`, `今日の運勢`에는 전문·대형 점술 사이트가 다수 노출된다.
- しんだんラボ가 이 키워드의 포괄적 1위를 노리는 것은 현실적이지 않다.
- 현재 강점은 이름별 고유 URL, 십간별 결과 URL, 혈액형 조합 URL이 이미 있다는 점이다.

판단: 헤드 키워드용 신규 계산기를 늘리기보다 **각 기존 결과의 설명 품질, 내부 링크, 계산 한계 고지, 고유 검색 의도**를 강화한다.

#### 4. 얼굴·외모 진단은 보류

- 일본의 `顔タイプ診断®`은 협회가 운영하는 명칭·자격 체계와 연결되어 있다.
- 사진 업로드형 구현은 개인정보와 이미지 처리 비용까지 발생한다.

판단: しんだんラボ에서는 `顔タイプ診断` 명칭을 그대로 사용한 도구나 사진 분석형 관상 진단을 당분간 만들지 않는다. 향후 만들더라도 사진 없이 답하는 독자적인 `顔の印象セルフチェック` 등으로 별도 검토한다.

### 오늘 발견한 사이트 내부 문제

1. 홈페이지와 선택형 퀴즈 시작 페이지에서 닫는 태그가 `</main>`이 아니라 화면에 `main>`으로 출력되고 있었다.
2. 홈페이지가 카드 목록과 한 문장 소개만으로 끝나 사이트의 목적·콘텐츠 제작 방식·진단 한계를 충분히 설명하지 못했다.
3. 선택형 퀴즈 시작 페이지는 소개문 한 문장뿐이고, 무엇을 기준으로 결과를 내는지 설명이 없었다.
4. 선택형 퀴즈 결과 페이지는 유형명과 짧은 설명 한 문단뿐이라 검색 사용자와 AdSense 심사 관점에서 고유 정보량이 부족했다.
5. `本当の性格タイプ診断`에 `MBTIだけじゃ分からない`라는 표현이 남아 있었다. 공식 MBTI와 무관한 독자 진단이므로 `16タイプ診断だけじゃ分からない`로 일반화하는 편이 안전하다.
6. 운영 목적과 편집 기준을 독립적으로 설명하는 페이지가 없었다.

### AdSense 판단

Google의 공식 안내는 텍스트가 충분한 완성된 사이트, 고유하고 사람에게 도움이 되는 콘텐츠, 명확한 탐색 구조를 요구한다. 기존 사이트는 기능 자체는 작동했지만, 선택형 진단의 시작·결과 페이지와 홈페이지가 지나치게 얇았다. 오늘 작업은 이 약점을 직접 보완한다.

단, 이 개선이 승인 자체를 보장하지는 않는다. 배포 후 Google이 페이지를 다시 크롤링하고 AdSense 심사가 갱신되어야 하며, 실제 거절 사유는 AdSense 대시보드의 문구를 기준으로 판단한다.
