# しんだんラボ プロジェクト範囲

最終更新：2026年9月3日

## 対象

このリポジトリと運用記録は、日本語版の診断サイト **しんだんラボ（shindan24.com）** だけを対象とします。

- 対象ユーザー：日本語で検索・閲覧する利用者
- 対象コンテンツ：16タイプ、性格診断、相性、恋愛、推し活、姓名判断、血液型占い、簡易四柱推命など
- 対象データ：shindan24.com の Search Console、GA4、AdSense、検索順位、共有・完了・再訪データ
- 対象市場：日本の検索需要、SNS上の共有行動、日本語コンテンツの品質

## 除外

次の情報は、このプロジェクトの企画・順位付け・SEO・AdSense判断・コード変更の根拠に混在させません。

- 韓国語版診断サイトのコード、検索語、KPI、ロードマップ
- 業務用計算・変換・文書ツールサイトのコード、資料、検索語、KPI、ロードマップ
- 他サイトのAnalytics、Search Console、AdSense、ドメイン設定、広告審査状況
- 他プロジェクトの自動化、日次レポート、競合調査、機能候補

複数プロジェクトが混在する資料が共有された場合は、しんだんラボに明示的に関係する部分だけを使用し、それ以外は参照・転記・実装しません。

## 運用ルール

1. 新しい判断を行う前に、対象ドメインが shindan24.com であることを確認します。
2. 日本語検索需要とサイト固有データを優先します。
3. 外部資料を使う場合は、日本版への関連性と出典を確認します。
4. 他プロジェクトのURL、計測ID、ブランド名、機能一覧、作業ログをこのリポジトリへ保存しません。
5. 他サイトとの相互リンクや共同施策は、利用者から明示的な指示があった場合にのみ検討します。
6. リポジトリの自動検査で、他プロジェクト固有の識別子が混入していないか確認します。
